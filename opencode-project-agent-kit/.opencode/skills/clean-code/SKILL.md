# Clean Code

Prefer:
- meaningful names,
- small cohesive functions,
- single responsibilities,
- explicit dependencies,
- low coupling,
- simple control flow,
- limited duplication.

Avoid:
- god classes,
- speculative abstractions,
- meaningless names,
- unnecessary comments,
- deep nesting,
- unrelated refactoring.

Comments should primarily explain why.
