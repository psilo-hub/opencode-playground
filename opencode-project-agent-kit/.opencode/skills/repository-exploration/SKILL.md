# Repository Exploration

1. Identify task scope.
2. Identify likely module/package.
3. Search for symbols and domain concepts.
4. Inspect highest-value results.
5. Follow references selectively.
6. Stop when sufficient evidence exists.

Never recursively inspect the whole repository without a concrete reason.

Prefer structural summaries over file dumps.
