# Git

Use Git history when it provides meaningful evidence about intent or behavior.

Prefer focused commands:
- status,
- diff,
- log for relevant paths,
- blame for specific lines when necessary.

Do not flood context with complete repository history.

Keep changes focused and avoid unrelated modifications.
