# Task Decomposition

Break work into independently understandable steps.

For each step identify:
- goal,
- affected module,
- prerequisites,
- expected outcome,
- tests,
- downstream dependencies.

Prefer small steps that can be independently verified.

Use TODO IDs to represent persistent dependencies.
